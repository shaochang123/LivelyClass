# Lively Class——AI教育Agent

**语言 / Language：** [简体中文](README.md) | [English](README.en.md)

将有使用权的教材、讲义和知识型 PDF 转成可溯源的中文教学视频与 PPTX 课件。支持文字提取、本机 OCR、课程规划、讲稿、SVG 图示、配音及视频合成。网页可查看讲稿、PDF 页码、原文摘录和知识关系，并下载 MP4、PPTX 与场景数据。

**真实 AI 模式**使用本机 Ollama 或兼容服务；**确定性演示模式**无需模型和密钥，明确标注为规则生成。来源匹配、模型审稿和计算检查都有各自的范围，教学内容仍需人工复核。

## 四项核心能力

- **原文课程：** 新网页逐页复制全部教材提取文本作为字幕与配音输入，不经过知识点筛选。记录原页、字符区间与文本摘要，导出前检查遗漏、重复、重排或改写；PPT可以概括。扫描件以OCR提取结果为准。
- **自动编排：** 十三套模板包含数理化、人文与专业课程模板族。由本地模型阅读内容识别学科，自动选择模板、版式及图示或动画；数理化使用图形与推演，人文使用场景漫剧。网页无需手动选择呈现方式、模板或动画类型。
- **个性化学习路径：** 在“个性化学习规划”中填写已有基础、学习目标、计划天数与每天可用时间。模型输出逐日学习、复习与自测建议，每日引用实际课程片段及PDF页码，程序核对片段覆盖与时间预算。结果可在线查看并下载Markdown或JSON，原文课程保持完整。
- **双路径动态呈现：** 数理内容可调用Manim生成可计算图形与过程；文科场景漫剧通过人物、地点与镜头规划调用绘图或视频接口。实际完成的媒介在结果中显示。Manim构造须通过计算与渲染校验；场景漫剧须配置绘图或视频服务。PPT为静态关键帧，动态内容输出为独立MP4。

项目全名为 **Lively Class——AI教育Agent**，简称 **Lively Class**。**让知识跃然眼前，让课堂生动起来。** 内部 Python 包、配置变量和原有数据路径保留兼容命名。具体实现位置见[四项功能核对](docs/四项功能核对.md)。

网页采用浅色科技视觉：白色导航、蓝紫光晕首屏、蓝色操作按钮与留白工作区，支持桌面和移动端。顶部可直接定位课程工作台、自动编排和生成流程。

界面更新后可强制刷新浏览器；已启动的 Python 服务需重启后加载更新的模板显示名称。界面视觉约定见[界面视觉规范](docs/界面视觉规范.md)。

### 学科自适应与漫剧讲解

上传教材并选择真实 AI 生成，模型自动识别学科、选定风格与版式，再决定每段使用关系图、计算图形或场景绘制。需要调整受众、详略或画风时，可在“PPT编排要求”中描述。网页新建与重试均使用自动编排，不会从旧任务恢复手动模板或动画设置。自适应设计按课程内容生成配色，程序检查可读性并保留必要的颜色调整记录。

文科采用场景漫剧：模型先设定世界观、人物外貌服装与地点，再按原文安排环境远景、人物行动和细节特写，形成连续故事或意象序列。教材原文完整作为旁白和字幕，不分配给固定的讲师与学员轮流说话。每镜通过绘图或视频接口制作实际场景素材，PPT收录场景关键帧和完整讲者备注，MP4使用原文音轨一次。仅接绘图时输出插画分镜；接视频时使用动态片段，不把静图序列称为人物动画。旧版师生对话任务保留原记录。

学科名称与模板路由分开：模板族依据当前材料的表达需求选择；公式、几何与可计算机制走数理模板，实体关系、表结构及系统依赖走专业结构模板，不因所属领域广义上属于STEM就一律使用数理版式。接入时注意：Seedream类图片模型负责绘制，Seedance类视频模型负责动态片段；火山方舟根地址为`https://ark.cn-beijing.volces.com/api/v3`，分别填入账户实际开通的模型ID与密钥。配置与测试步骤见[学科选版与漫剧接入测试](docs/学科选版与漫剧接入测试.md)。

API创建与重试继续兼容 `style_mode=subject|template|adaptive|comic` 及原动画参数。新网页的AI任务统一提交 `narration_mode=source_verbatim`、`style_mode=subject`、`animation_mode=auto`；确定性演示使用基础图文。学科识别和模板选择分两次调用，逐段画面工具由模型规划。旧API客户端未传新参数时继续使用提炼讲解流程。原文课程的理解与规划仅允许本机或已授权学院服务器模型，不使用DeepSeek或云端语言模型。

原文课程导出烧录字幕、SRT、VTT、逐字JSON、全文与逐页核对记录。字幕时间来自真实逐句音频，完整画面缩放至独立字幕栏上方。PPT不嵌入音视频，MP4中每段原文配音使用一次。数理连续场景沿用构造与计算核验，未完成的场景保留SVG及具体记录。

“原创插画与视频接口”默认关闭，支持Images兼容绘图网关与Seedance视频任务；场景漫剧需启用至少一种，同时启用时优先视频。每课素材上限默认12、最多200，分镜数超过上限时在发起素材请求前提示调整，不自动增额或用对话人物补缺。经显式同意后仅发送场景描述，素材进入实际PPT/MP4并标为AI情境演绎。角色与地点设定通过共享文字描述传给各镜头，尚无参考图条件控制，实际外观连续性需核对。媒体密钥仅在任务内存中使用，不写入SQLite、文件或浏览器存储。小云雀等服务需要兼容网关。详见[原文课程与学科编排](docs/原文课程与学科编排.md)和[学科风格与漫剧](docs/学科风格与漫剧.md)。

即梦文生图3.0可直接选择“即梦文生图（API Key）”：根地址填`https://openapi.cv.volces.com`，模型填`jimeng_t2i_v30`，密钥填API Key Secret。此入口使用Bearer鉴权，与`visual.volcengineapi.com`的AK/SK签名入口分开。提交后保存任务ID，查询重试不重复创建；提示词超过800字符会在素材请求前提示调整，不截断内容，也关闭服务端提示词扩写。文科分镜逐镜核对原句含义、角色与道具身份和事件顺序，拒绝结果进入有限修订，首次记录保留。模型核对之外仍需查看实际画面。

## 快速开始（Windows）

在项目根目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[test]"
.\.venv\Scripts\python -m uvicorn zhijiang.main:app --host 127.0.0.1 --port 8765
```

打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)，选择[原创示例 PDF](examples/binary_search_original.pdf)，确认使用权，使用演示模式和 Windows 系统语音体验。完成后查看讲稿、来源、视频与课件。**在启动服务的终端按 `Ctrl+C` 关闭服务**；关闭浏览器不会停止服务。

Python 要求 3.11+，已在 Python 3.13 上验证。系统配音需要 Windows 中文语音；其他环境可配置兼容语音 API。`imageio-ffmpeg` 提供 FFmpeg，无需安装系统 FFmpeg。

网页突出资料上传、自动编排、声线试听与生成结果，使用更大的正文和简洁标签。模型、语音及媒体接口设置默认折叠，未配置的模型或语音设置会展开；输入有误时自动展开对应设置。生成提示与技术信息收进“生成记录”，原文摘录可在每段讲稿的“原文依据”中展开查看。

## 模型与动画配置

首次配置可复制模板；已有 `.env.local` 时直接编辑，保留现有配置：

```powershell
Copy-Item .env.local.example .env.local
ollama list
```

将 `ZHIJIANG_LLM_MODEL` 改为已安装的模型名，启动 Ollama，再重启 Web 服务。数学对象模式需要支持图像输入的模型；本机使用 `qwen3.5:9b`，建议开启 `ZHIJIANG_OLLAMA_SEMANTIC_THINKING=true`。`.env.local`、模型权重、上传资料和生成物均被 Git 忽略。网页也可配置单次任务；外部服务须确认发送教材文本、用于来源修订和选图的原页图像或讲稿。

Windows 网页默认勾选“在本机记住密钥”：模型与语音密钥由 Windows 当前账户加密，存入已忽略的 `data/private/credentials.dpapi`。刷新或重启后显示“已保存”，留空即可使用；密钥按用途、提供方和 API 地址分别保存，更换地址不会借用旧密钥。“清除保存”删除当前地址的保存项；取消勾选仅停止新密钥保存。浏览器只保存地址、模型和声线等非密钥设置，不将密钥写入 SQLite、课程 JSON 或网页响应。其他平台使用本机环境配置或单次任务密钥。

可选 `ZHIJIANG_OLLAMA_NUM_GPU` 控制 Ollama 的 GPU 层数，留空使用自动分配。本机 8GB 显存同时运行桌面应用时使用 `24` 保留余量；其他机器需按实际资源调整。推理速度与显存、内存及模型有关。

项目不设置模型生成 token 限额或推理总时长上限：所有 Ollama 阶段均请求 `num_predict=-1`，兼容 API 不传生成长度上限。上下文记忆容量默认沿用 Ollama 设置，也可用 `ZHIJIANG_OLLAMA_CONTEXT_TOKENS` 自行配置正整数，没有项目写死的最大值；本机配置为 `16384`。上游若仍截断，会重新请求完整结果并明确报告服务端原因，不将截断 JSON 标为成功。详见[生成配置与恢复](docs/生成配置与恢复.md)。

普通语义推理阶段沿用模型/服务的采样配置，不再强制零温度；推理开关仍由用户控制。

`ZHIJIANG_OLLAMA_THINKING_LEVEL` 可填写服务实际支持的推理档位，留空沿用服务默认值；不支持该档位会明确报错。只有布尔推理开关的模型仍使用 `ZHIJIANG_OLLAMA_SEMANTIC_THINKING`。不同模型、档位与硬件的结果不能直接当作模型能力排名。

```powershell
.\.venv\Scripts\python -m pip install -e ".[math-animation]"
```

| 动画方式 | 当前行为 |
| --- | --- |
| `auto` | AI 默认；直接生成完整来源上下文中的讲稿、SVG 关系/过程/比较图与逐步呈现。严格复核使用独立来源审查和 Manim 场景。 |
| `visual` | 默认直接生成教学图示；严格复核使用通用 Manim 场景。 |
| `geometry` | 通用二维数学对象推演；需要 TeX，失败时明确报错，不回退到关系图或原页高亮。 |
| `math` | 二维线性变换专用推演；需要相应原文和 TeX。 |
| `basic` | AI 默认生成简洁教学图；严格复核使用基础讲稿路径，确定性演示使用规则要点图示。 |

原生关系图与原页讲解无需 TeX；可计算几何和专用数学推演需要 `latex`、`dvisvgm`。系统语音、Kokoro、外部 API 与续跑见[生成配置与恢复](docs/生成配置与恢复.md)，图示和 skills 见[教学图示与动画](docs/教学图示与动画.md)。

高级API的“生成策略”默认采用 **直接生成**（`content_checks=warn`）。普通课件读取完整引用页及相邻页，生成后对照原文与可读取的页图修订标题、讲稿和图示，重点保留否定、条件、例句及角边身份。该修订使用同一模型，不代表独立事实审核；修订不可用时保留课程并记录提示。`auto` 和 `visual` 可尝试构造实际数学对象及连续演示；失败时保留普通图示，不使整节课失败。引用身份、文件格式与渲染可执行性仍由程序处理。可选择 `strict` 启用原有严格流程。创建和重试都保存该选项。详情见[直接生成与失败恢复](docs/直接生成与失败恢复.md)。

普通课件的来源修订会检索 PDF 中实际嵌入的图片区域，由模型选择相关候选编号，程序解析页码与裁剪边界。整页扫描图不会被当作插图；扫描页和矢量图仍可依据原页图像裁剪。选中原图先单独读取，再对齐标题、讲稿和画面；这仍是同一模型的修订。没有合适原图时保留教学图示。数学演示先编译对象依赖图，再根据实际工具计算量规划动作与测量；修订动作时保留有效对象。带编号的对象名称可以用于测量标签，数值仍由实际对象计算，不能预填答案。

来源修订与原图对应阶段也遵循推理设置。普通 `auto`、`visual` 模式可以使用配置的数学规划和复核模型。Ollama 云模型不发送本地 GPU 参数或负数生成限额；临时限流遵循服务的重试提示，月度额度耗尽单独报告。数学演示逐步绑定实际关系，差异与反例可使用不相等核验；每步均进行来源和数值对应检查。

修订内容完整但缺少逐页标题时，保留已有知识点标题，不额外重写讲稿。模型把课程总标题重复用于每一页时，也使用对应知识点标题。来源编号、口播句子引用和必要图示内容仍按完整契约处理。

自动对象演示先依据原文区分定量关系、真实机制与抽象阅读顺序或概念比较。抽象顺序和比较使用教学图示，避免为阅读视角编造坐标测量；定量、真实过程及不确定内容保留对象演示尝试。判断按来源内容进行，记录依据，不使用教材名单或学科排除规则。

## 自然讲解配音（可选）

可在独立 `.venv-tts` 中运行 **Qwen3-TTS 0.6B Base**，以本机参考语音匹配讲解声线。网页试听随配音选择切换：系统语音使用实际配置的 Windows 声线；AI 语音根据当前填写的 API 地址、模型、音色自动查找对应试听，没有时点击“生成试听”，也可“重新生成试听”。试听使用与课程配音相同的接口和密钥解析方式，外部语音服务需确认发送原创试听文本。换设置会停止旧音频，已有试听可在刷新后恢复；未安装或服务不支持的模型/音色会报错，不改播其他声线。AI 配音用于独立视频；PPT 保留完整讲稿备注。试听、声音提示、权重和 `.env.local` 均被 Git 忽略；参考音频与讲稿留在本机。安装、启动与 CPU/GPU 配置见[本机自然讲解配音](docs/自然讲解配音.md)。

启动语音服务使用 `.\scripts\start_voice_service.ps1`，在其终端按 `Ctrl+C` 关闭。设置 `ZHIJIANG_DEFAULT_VOICE_MODE=ai` 后，新网页默认使用已配置的 AI 声线；旧任务和未指定配音模式的 API 保留原行为。直接生成模式下，AI 配音不可用会切换整节课到系统语音，记录提示并披露实际声线。音色与自然程度需要试听判断。

## PPT 模板与课程导演

模型从数理化、人文、专业及通用模板族中自动选择课件风格与版式。模板包含深色演示、纸上讲解、学术课堂、杂志叙事及科技风等视觉方案；模板说明参与 AI 规划，PPT 和视频共用背景、标题和图示。真实 AI 根据内容选择画面工具、允许的版式和静态教学步骤，演示模式使用规则排版。模板内部 ID 保持兼容，旧任务仍可读取；高级 API 仍支持显式指定模板。

教学图形可按含义选择概念椭圆、操作框、数据平行四边形、文档和结果图形；菱形用于确有条件判断的节点，比较页使用开放布局。节点过窄或文字拥挤时自动调整构图、拆成连续页面，保留对象、关系与条件，口播只播放一次。往返关系使用不同箭头通道和标签位置；浅色装饰色不会直接用于低对比度的知识文字。与边标签重复、没有连线和说明的独立标签框合并到对应边上，完整别名及原草稿保留。导出失败时保留已合成配音；重试会复用讲稿、音色和文件校验一致的音频。切换模型提供方须填写对应地址和模型，服务地址与模型名称可在刷新后恢复。

文件类型、功能矩阵、真实本地模型与长视频压力测试可复现，见[生成稳定性与功能测试](docs/生成稳定性与功能测试.md)。导出阶段失败的普通任务可运行 `python scripts/resume_job_export.py YOUR_JOB_ID`，使用保存课程和本地语音恢复导出，不重新调用语言模型。

新生成任务的 **PPT 是静态课件，讲解视频是独立 MP4**，PPT 不嵌入视频或配音。两者共用模板、图示与配图；数学对象在 PPT 中展示静态步骤，在视频中连续演示，每段讲稿只播放一次。可引用教材中的相关插图或例句图片，出处与裁切信息留在备注；复杂连线与长标注使用完整展示区，必要时为原图单独分页。标题约 36–44 pt，正文至少 24 pt，长文字拆页。旧生成文件保持可访问，重新导出采用新行为；网页AI新任务由学科识别结果确定模板，演示模式使用 `paper`。详见[课程导演与 PPT 模板](docs/课程导演与PPT模板.md)。

新任务将口播和画面分开：完整讲稿保留在备注与网页，画面使用简短对象名、实例表格、比较、关系箭头与概念图，不把完整口播堆成文字栏。严格模式将短说明和每条连线绑定完整讲稿依据，并逐项复核条件、否定和关系方向；拥挤时调整构图。现有数学 SVG 与连续场景优先保留。

直接生成模式包含封面、学习路线与结尾。模型从完整讲稿句子中选择核心知识结论，程序复制原句，避免把课程最后的期刊或组织介绍自动当成总结。路线规划失败时保留已有导航并提示，生成继续。

严格复核模式先将课程要点绑定到完整讲稿，再单独设计简洁画面；完整原句是复核依据，不要求全文上屏。独立读取的来源命题帮助恢复知识图示，具体字段与值可生成示例表格；没有依据的箭头会被拒绝并记录。模型复核不证明讲稿本身正确。中文候选词边界使用主依赖 `jieba`，无需仅为普通课件安装数学动画扩展。

严格复核路径包含具体示例规划：按内容选择属性记录、实例矩阵、对照、关系、时间线、数值算例、注释或结论，使用开放构图，保留导演选择的分栏与成对行布局。明确的“对象从来源移动到目的地”可绘成保留对象身份与方向的箭头，并列环节不被补成因果链。算例使用有界四则运算核算，并另查来源含义；图示拒绝后保留字面来源或先前已复核画面及拒绝记录，不虚构新例子。短句和连线按来源句的长度估算逐步出现、聚焦或绘制时间，尚未做语音强制对齐；已有连续数学演示优先保留。流程、边界与实际验证见[具体示例与画面多样性](docs/具体示例与画面多样性.md)。

严格模式的基础 AI 讲稿必须覆盖全部已规划知识点。选中引文中的显式数字计算和记录会检查口播数值是否遗漏；重试仍遗漏时用完整原文及条件补回，在网页提示和 `script-coverage.json` 中说明。该检查不覆盖所有教材例题、中文数词、代数或证明，也不以数值出现代替关系正确性复核。

中文来源先连接 PDF 的物理换行，再按句子或分句限制摘录长度，避免单位与条件被换行截断；无标点的长公式仍需核查原页。

严格模式将学习路线合并为最多四组连续主题（五个片段以上至少两组，十二个片段以上至少三组），并核对主题与本组实际内容，结尾独立选择并复核完整知识结论，不再逐页列出全部标题。PPT 包含封面和结尾；新版完整视频同步显示封面 3 秒、结尾 5 秒，两段有意静音，不重复讲稿。旧生成文件仍可访问。

## 可检索教学素材

内置 **100 个原创线条符号和 9 个有出处的 CC0 手绘插画**，覆盖生活农业、计算机、数学、物理工程、化学、生物、教育、医疗、金融、法律、汽车交通和历史。手绘书本保留彩铅纹理，西瓜和灯泡保留自由笔触；外部原作的作者、来源与许可逐项列在素材目录中。网页默认开启“自动检索插画与符号”，真实模型从最多 8 个本地候选中选择每页最多一张主要配图、两枚辅助符号；同一对象优先选择插画，演示模式使用确定性匹配。配图绑定对应的实例或要点，合计占普通页面不到 8% 的面积，知识重点与教学演示占主体。知识与数学关系仍来自教材和独立演示。

检索关键词与对象别名分开：相关学科词不能自动作为图片名称，例如肺部图不会被标为肺泡；英文别名按词边界匹配。一个对象只提供一个优先配图候选。未找到合适素材时保留知识画面并记录缺口，当前九个手绘条目尚未覆盖所有领域。

素材目录是 [zhijiang/assets/visuals](zhijiang/assets/visuals/README.md)，每一级目录的 README 描述子目录及素材。支持新增 SVG 和透明 PNG，使用随主依赖安装的 `resvg_py==0.5.0` 生成透明兼容图。索引、预览与缓存存于忽略的 `data/`：

```powershell
.\.venv\Scripts\python scripts/index_visual_assets.py --check --rebuild --contact-sheet
```

创建及重试 API 支持 `use_illustrations`，默认开启，重试未填写时保留原选项。目录描述或素材变化会使配图规划缓存失效。添加素材与验收流程见[素材库与共享画面](docs/素材库与共享画面.md)。

基准默认采用本机模型和系统语音；脚本禁止 DeepSeek。经授权的公开选页可在独立结果目录中增加 `--model gemma4:cloud --allow-ollama-cloud` 做云模型对照，发送许可写入运行记录；不同模型和配置分别统计。恢复导出另行记录，保留首次失败；`audit` 可重新检查生成物，`package --include-media` 可打包完整静态 PPT 与独立视频。扩展版命令增加 `--suite benchmarks/textbooks_v2 --root data/textbook-benchmark-v2`。

素材绑定时，超出当前讲稿范围的句子编号不再使 PPT/视频导出崩溃；程序跳过该句子的配图回退，不把它绑定到另一个句子。新画面缓存使用更新的版本，已生成文件保持可访问。

原页修订会核对所有知识点编号。批量响应缺页、重复编号或字段无效时，保留完整响应中有效的页面，仅对其余页面单独生成讲稿和图示；单页修订失败会记录原因，保留该页原稿，继续使用其他成功修订的页。不会把只修订一页的响应当成整批完成；画面引用的句子编号须属于本页口播。

修订中的同值重复条件标记可按结构归位；条件标记相互冲突时继续要求澄清。句子编号错误时，程序提供本页完整口播的编号列表，模型仅修复对应关系，口播不重写。原图先单独读取用途，视频封面、装饰和不能确认的图片不作为机制图；共同归类使用无向关系。Ollama 知识提取使用 JSON 输出与完整类型校验，避免在该阶段依赖复杂原生解码约束。

```powershell
.\.venv\Scripts\python scripts/benchmark_textbooks.py prepare
.\.venv\Scripts\python scripts/benchmark_textbooks.py run
.\.venv\Scripts\python scripts/benchmark_textbooks.py report
```

工程成功、关键词出现和教学正确性分别评价；清晰模拟扫描与英文选章的结果不代表拍照、手写、中文教材或整本书的性能。

## 流程

[![从 PDF 到视频与课件](docs/workflow.zh.svg)](docs/workflow.zh.svg)

严格模式的定性图示先独立理解来源，再提取命题，按主语、谓词、宾语及条件构建知识关系。模型选择来源编号，程序绑定引文并共享 SVG/动画布局。参数化几何通过受限表达式与数值检查执行，不执行模型代码。详见[架构与接口](docs/架构与接口.md)。

严格模式的定性场景先按标题检索输入中的当前页及相邻页，复核必讲范围，再绑定事实和口播；不再只读短引文前后三句话。PDF 行内斜体的完整外文示例由程序保留，原页注释提供按步骤切换的局部放大。归因、实测与剩余问题见[Agent 与模型能力诊断](docs/agent-model-capability-2026-10.md)。

数学对象模式先对照教材原页图像恢复公式和图形，再分别生成教学设计、数学构造图和讲解操作。通用构造包括点、线、函数、参数曲线、中点、垂足、刚体变换、等面积分割、隐式距离轨迹、逆函数与有限展开；由程序计算依赖坐标、导数和系数，不按教材标题选择预制分镜。SVG 和视频采用等单位坐标缩放。

数学构造按依赖顺序编译；派生量在每个运动帧重新计算，静止讲解保留已核验状态。关系检查直接测量实际对象的距离、角度、面积、函数值和导数，拒绝只校验参数恒等式；镜头范围覆盖运动采样，检查可见点与标签锚点。计算结果与配音、SVG、视频共享，舍入值标为近似值。结构、来源与数值失败会进入明确的修复或失败状态，不以模型审稿代替数学检查；这些有限检查仍不能保证所有知识正确。

坐标测量保留正负号，距离与非负夹角分别计算；可使用有向角。旋转后从实际顶点化简面积和长度，保持渲染数据检查。全程关系与指定步骤的终点关系分开验证；镜头按可见有限对象确定等单位范围，远端函数尾部裁出窗口，避免压缩主体。网页可分别填写同一 API 上的“数学规划模型”和“独立数学复核模型”：生成模型读取原页并审核画面，规划模型生成构造与操作，复核模型检查来源与文字；留空则使用生成模型。独立复核应选与规划不同的模型。角色与实际调用分别记录；复核不等于正确性保证。Ollama 云模型即使使用本机地址也需要发送许可，详情见[配置参考](docs/生成配置与恢复.md#通用数学对象模式)。

数学审稿直接对照教材原图与每步 SVG，先记录来源、几何、连续操作的观察再判定批准。相邻线段可按共同端点测量顶点内角；有向角弧可保留完整扫角，并核验实际弧端点。复杂计算表达式拆为受限的派生节点，不放宽 AST 限额。数值口播仅修复出错句，保留已核验对象和操作；运动帧持续检查，静止讲解保持已核验终态。

刚体变换的原图与副本共享对象身份。前后比较的原图需设为 `reference=true`，画面会淡化并标为“参照”；移动同一对象时隐藏原图。角弧、圆和函数曲线也可刚体变换，旋转后的函数按参数曲线绘制。

原页识别后先独立列出必讲条件、结论和已解核心算例，再规划画面；候选完成后逐项核对实际口播、操作取值和渲染几何。参数曲线上的点可用于测量角弧首尾的实际拼接。数学课按内容安排 3–10 步，简短完整的定性口播无需补字。没有完成标记的模型响应不能作为结果，服务中断至多重试两次。当前修复与教材联合验收记录见[数学修复报告](docs/math-repair-acceptance-2026-10.md)。

来源主语绑定实际对象类型、顶点数及测量依赖，拒绝用无关占位图形替代教材对象；概念照片与装饰插图允许用等价的正确数学示意说明。`align` 按两组真实锚点与方向计算连续刚体对齐，不猜旋转角，不改变长度和面积；角度和、角差标注弧度。持续的语义构造错误会触发有限次数的设计修订，原稿与拒绝原因均保留。

来源主语可明确记录同类对象的数量，绑定时逐个核对类型、可见性和测量依赖，拒绝重复或无关对象。不同类型的并列主语分别保留；已给出的带数量和对应标注的图解方案也按核心算例检查。构造清单中的非有限初态在审稿前拒绝，不能让隐藏辅助对象从无穷远开始。

来源清单先对照原页图像生成，再独立核对翻译、条件和算例；不通过时先修复来源含义。构造完成后，工具返回实际坐标、面积、长度与角度，并检查现有对象和自由度能否表达必讲内容。通用交点工具支持两条直线/射线/线段或两个圆；线与射线按实际窗口延伸，曲线上动点须处于真实绘图区间。完整行为 JSON 的个别字段无效时仅修复对应字段，其他已验证字段保留；损坏 JSON 不按局部正文接受，最终仍须通过完整契约及数学、来源、SVG 和运动检查。

构造修复支持受限的新增、替换和删除补丁，保留未修改的正确对象，并按真实依赖排序。连续两次操作修复失败会返回构造层，即使两次错误措辞不同。构造草稿最多 32 项，分割后核心对象仍最多 48 项，含点名的渲染契约仍最多 64 项。补丁不能绕过来源和实际动画检查。

编译器也会为初次生成的完整对象图解析依赖顺序，保留原表达式、对象身份与合法绘制顺序；重复 ID、缺失依赖和循环不会被猜补。普通课程演示中的非有限初态和主体被压缩的绘图范围问题直接修复对象图，避免反复改写无关口播。候选、实际编译顺序与拒绝原因仍保存在本地记录中。


来源覆盖与构造可表达性按每批两项复核，汇总保留全部要求和拒绝项。已核对的中文来源清单由程序逐字绑定到教材说明卡和配音：定义及条件先讲，算例对应实际演示步骤。说明卡不算数学证明，动态数值仍来自实际对象测量，自由口播继续受数字校验约束。说明卡播放结束后才开始该步数学运动；讲稿保留对应来源说明。逐组验收同时查看来源卡与数学运动帧。

具体几何图解算例还会独立提取来源对象身份图，保留部分、整体、位置和编号归属。模型将实体绑定到真实对象；程序核对类型、相对位置与有限多边形的顶点包含关系，并为来源身份分组及其变换副本分配一致颜色。未参与讲解的静态辅助点隐藏；明确平移方向须与实际采样坐标一致。同色共线的线段、射线或直线完全遮蔽时会要求隔离显示或修正表达。以上为受限结构和运动检查，仍须人工核查来源与实际成片。

## 当前边界

- 单机顺序队列，一份 PDF 生成一节课；同一数据目录只允许一个 Web 服务，重复启动会退出，不中断原任务。上传上限 200 MB，无固定页数或目标时长上限；长教材耗时和产物大小会增加。
- OCR 不保证复杂公式、表格和版面恢复准确；没有人工公式确认界面。
- 数学对象模式读取混合页中的原页图像和公式，识别结果及模型复核仍可能出错；须对照原页核查。表达能力限于受限二维构造和唯一实函数分支，模型规划、模糊原页或不支持的数学操作会明确失败。
- 严格模式的一个定性场景使用一个来源页，可重新选取输入中的相邻页；需跨页联合解释或缺少标题所需依据时明确失败。范围复核和模型审稿仍可能误判，不能当作事实正确性保证。
- 网页可查看课程和来源，尚未提供项目列表、知识点选择编辑、讲稿编辑或人工审核发布流程。
- PPTX 为静态课件，标题和备注可编辑；SVG 路径不是独立的 PowerPoint 形状。配音与连续动画位于独立完整 MP4。
- 受限二维场景、来源关系追踪和原文课程的SRT/VTT字幕已接入；复杂三维机制、跨章推理、事实证明与课程ZIP导出尚未实现。字符覆盖检查不代表OCR或图示语义的独立正确性验证。
