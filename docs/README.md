## 仓库目录职责

```text
Book2Course/
  README.md / README.en.md    简体中文 / 英文项目入口
  AGENTS.md                  仓库协作约定
  pyproject.toml             包、依赖与可选安装项
  requirements-tts.txt        隔离的 Qwen 配音环境依赖
  .venv-tts/                 本机语音环境（忽略提交）
  .env.local.example         可提交的配置模板
  zhijiang/                  服务、来源理解、课程与媒体模块
    static/                  当前原生网页
    powershell/              Windows 系统配音
    assets/visuals/           领域符号与有出处的手绘插画，每级有说明
  tests/                     单元、API、模拟模型与媒体回归
  scripts/                   示例、媒体验收、文档导出工具
  examples/                  原创样例、外部教材来源清单
  demo/                      本机示例媒体及课程 JSON（忽略提交）
  docs/                      当前指南、契约与逐次验证记录
    archive/2026-09/         九月首版说明快照
  submission/                本机历史发布包（忽略提交）
  data/                      本机资料、任务、缓存、模型、日志（忽略提交）
  output/pdf/                当前文档导出（忽略提交）
```

生成模块保持原路径，模块职责按业务阶段列在[架构与接口](架构与接口.md)。

## 验证记录的分工

| 记录 | 说明 |
| --- | --- |
| [教材泛化验证](generalization-validation-2026-10.md) | 四领域真实选页、空提示词、模型生成、失败与媒体/内容结果。 |
| [真实资料修复](content-design-validation.md) | 来源理解、设计失败与实际修复，保留未通过项。 |
| [长教材续跑](long-textbook-progress.md) | 扫描教材进度、OCR 与分批缓存，记录当时状态。 |
| [通用场景验证](general-scene-validation.md) | 开发者预写的五领域执行器回归，不是自动规划效果。 |
| [数学动画验证](math-animation-validation.md) | 专用二维线性变换的计算、渲染和口播检查。 |
| [数学构造修复与联合验收](math-repair-acceptance-2026-10.md) | 通用构造、实际关系、模型角色及八组冻结回归；当前终验进行中。 |

## 文档维护

改变使用方式、配置、依赖或支持范围时，同步更新两个 README、详细参考、实现状态与验证记录。新能力应有真实代码和测试或实测证据；规划项在验收前保持“待实现 / 部分实现”。

执行 `python scripts/build_documents.py` 导出当前说明书，需要 ReportLab（包含于 `.[test]`）。输出为 `output/pdf/LivelyClass_绘声绘课_产品说明与使用指南.pdf`，支持目录、章节书签、中文表格与跨页表头。历史打包脚本使用归档快照，见[归档说明](archive/2026-09/README.md)。
