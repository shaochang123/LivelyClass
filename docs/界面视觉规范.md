# Lively Class——AI教育Agent 界面视觉规范

本次改版沿用此前按新致官网截图整理的蓝紫、云彩光晕与留白方向，品牌和内容使用Lively Class 自身标识。当前官网访问超时，未将本次实现描述为对官网现版的逐像素复刻。

## 颜色与层次

| 用途 | 色值 |
| --- | --- |
| 页面底色 | `#F7F9FD` |
| 面板与导航 | `#FFFFFF` |
| 正文 | `#192B48` |
| 次要说明 | `#62728B` |
| 主操作蓝 | `#2868EF` |
| 蓝色悬停 | `#1954CF` |
| 辅助紫 | `#8055C7` |
| 边线 | `#DDE5F0` |

蓝紫光晕集中于首屏，表单与结果使用浅色实底。主按钮实色，选中项同时使用边框和浅色底，不只依靠颜色区分状态。失败、完成状态分别使用红色和绿色文字及底色。

## 布局与交互

- 桌面内容区最大宽度 1200px，白色顶部导航固定，工作区使用表单与流程两栏。
- 窄屏将工作区改为单列，保留上传、模型配置、风格预览、声音及来源查看入口。
- 正文默认 16px；表单输入不小于 16px；首屏标题按屏宽调整。
- 使用 5–12px 圆角、细边框和轻阴影建立层级。首屏图形由本地 CSS 与 SVG 绘制，无第三方图片或字体依赖。
- 键盘焦点使用可见的蓝色外框，提供跳转工作台链接；减少动态效果设置会关闭平滑滚动和过渡。
- 导航只指向页面内已有区域，不增加登录、收费或外部提交入口。
