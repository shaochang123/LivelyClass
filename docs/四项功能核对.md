# 绘声绘课（LivelyClass）四项功能核对

更新日期：2026-10-20。

| 功能 | 实际实现 | 入口与输出 |
| --- | --- | --- |
| 教材全量保真与多模态转换 | 程序从提取文本建立逐页字符区间；讲稿、TTS输入、字幕采用同一原文，模型另做PPT摘要和图示 | 新网页默认原文课程；完整讲者备注、SRT、VTT、原文TXT、逐页JSON |
| 学科自适应PPT设计 | 模型先识别学科，再选择预建模板族；逐段规划布局、图示或计算演示。理科强调变量、公式与过程，文科组织背景、脉络、比较和有来源的情境 | 自动编排；结果显示识别学科、实际模板与实际媒介 |
| 个性化学习规划与建议 | 根据学习基础、目标、天数、每日时间生成学习、复习、自测安排；引用真实片段与页码，检查片段覆盖，按用户预算分配每日时间 | 可选“个性化学习规划”；在线查看、Markdown/JSON下载 |
| 面向学科差异的双路径动态传播 | 理科通过Manim计算与渲染对象演示；文科先规划世界、角色、地点和镜头，再调用绘图或视频接口生成场景。原文作为旁白，人物并非固定师生对话 | 静态PPT关键帧 + 独立MP4；缺少服务时提示配置，实际媒介记录在课程中 |

## 代码位置

- 原文：`literal_course.py`、`source_subtitles.py`、`literal_pipeline.py`。
- 学科/风格：`subject_routing.py`、`presentation_templates.py`、`course_styles.py`。
- 学习计划：`models.LearnerProfile`、`learning_plan.py`；创建/重试API字段为`learner_enabled/background/goal/days/minutes_per_day`，下载`/api/jobs/{id}/learning-plan?format=md|json`。
- 数理演示：`automatic_construction.py`、`visual_media.py`、`math_media.py`；使用Manim，不将静态SVG或独立PPT导出称为Manim-Slides运行。
- 场景漫剧：`drama.py`、`drama_renderer.py`、`generated_media.py`；Images兼容绘图或Seedance任务接口。

## 输出约定

原文逐字一致指PDF提取文本。扫描页须另核对OCR与原像素；复杂公式的视觉排版也不能由字符串一致推定。字幕时间按逐句实际合成音频安排，不是语音识别后的逐字强制对齐。PPT正文可摘要，讲者备注保留完整原文；视频画面底部显示完整的顺序字幕，PPT中不嵌入视频或音轨。

学习计划的目录及摘录来自实际课程，活动与自测为模型生成的建议，不冒充教材原题。实际朗读时长超过用户总预算时，会在计划中提示调整时间。

Manim构造须完成计算和渲染校验；失败时保留SVG并显示实际结果。场景漫剧接入实际绘图或视频服务后才能生产新画面；绘图分镜与动态人物视频分别标注。

产品界面、当前文档与新下载文件统一使用绘声绘课/LivelyClass。内部包名、环境变量、原始资料与历史产物保持兼容。
