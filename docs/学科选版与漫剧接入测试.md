# 学科选版与漫剧接入测试

## 测试对象

1. 用没有学科名称的上传文件名，提交有完整原文的短材料。先记录模型识别出的实际学科，再记录模板ID、理由及最终PPT。
2. 分别包含公式/计算、物理过程、化学关系、语言叙事、历史叙事和专业系统结构。模板族是视觉表达路线，不是广义学科门类：系统实体与表结构不因属于计算机科学而自动变成几何推演。
3. 文科保存人物与地点设定、故事弧线及逐镜计划。核对事件顺序、人物身份、原句编号和字符覆盖，不能仅凭分镜数量宣布故事正确。
4. 接入实际绘图/视频服务后，检查每镜返回文件、SHA256、PPT关键帧与MP4成片；插画分镜与真实动态片段分别记录。模拟HTTP返回只验证适配器，不能证明某家服务的画面效果。

## 绘图与视频配置

| 项目 | 图片生成 | 视频生成 |
| --- | --- | --- |
| 示例模型系列 | Seedream | Seedance |
| 网页协议 | Images兼容绘图接口 | Seedance异步任务接口 |
| 方舟根地址 | `https://ark.cn-beijing.volces.com/api/v3` | 同左 |
| 追加路径 | `/images/generations` | `/contents/generations/tasks` |
| 模型 | 账户实际开通的图片模型ID | 账户实际开通的视频模型/接入点ID |
| 产物 | 逐镜插画、PPT关键帧及静态分镜视频 | 逐镜动态素材、PPT关键帧及动态视频 |

模型ID及参数应以账户权限和服务文档为准，不替用户猜测某个付费版本。图片和视频密钥仅用于本次任务，不写入课程JSON、SQLite或浏览器持久存储。使用自定义服务时须兼容对应协议。

文科每个镜头使用一份实际生成素材。先核对镜头数与素材上限，再创建请求；视频轮询超时保留任务ID，不自动再提交付费任务。成片使用教材原文配音，不混入视频服务自动生成的对白或音乐。

### 即梦文生图3.0（API Key）

选择“即梦文生图（API Key）”，根地址为`https://openapi.cv.volces.com`，模型/req_key为`jimeng_t2i_v30`，密钥填API Key Secret。官方路径为`/api/common/v3/submit_task_v2`和`/api/common/v3/get_result_v2`。API Key ID不拼接到Bearer密钥中；`visual.volcengineapi.com`使用另一套AK/SK签名方式。

每次提交生成一份镜头素材，返回任务ID后持久化无密钥状态；超时续查不重复创建。对结果不明或首次拒绝的提交不自动重发。单镜提示词最长800字符，在全部素材请求之前核对，不截断人物、动作或条件。`use_pre_llm=false`关闭服务端提示词扩写，教学理解与分镜仍由本机/学院服务器模型完成。

逐镜来源核对先写原句含义，再判断人物、物件、动作和时间顺序是否一致。全部镜头必须有核对记录；不支持项进入最多三次修订，首次拒绝保留。此项模型核对不能替代对生成画面的人工检查。

官方说明：[即梦3.0](https://docs.volcengine.com/docs/JimengAI/DreamText-to-Image30-InterfaceDocumentation?lang=zh)、[API Key入口与鉴权](https://docs.volcengine.com/docs/AIGCAIzhongtaigongyongwendang/api-key-usage-guide?lang=zh)。

## 核验范围

人物跨镜头目前复用外貌、衣着、道具与地点的文本设定，尚未向接口发送角色参考图。因此实际一致性、动漫表现力及镜头动作必须看真实服务返回。没有配置服务时只能验证选版、分镜和适配器，分镜策划PPT须明确标注，不能当作已经绘制完成的课件。

官方接口：[图片生成](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)、[视频生成](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。
