# 学科风格与漫剧

Lively Class——AI教育Agent在网页自动选择学科模板、画面工具和漫剧呈现；高级 API 保留显式配置方式。新网页的字幕与配音逐字使用教材提取文本，PPT单独提炼，详见[原文课程与学科编排](原文课程与学科编排.md)。

## 使用

1. 上传有使用权的 PDF，选择真实 AI 模式。
2. 模型阅读内容后自动识别学科，选择学科模板、呈现方式与逐段画面工具，网页不再提供模板或动画方式下拉框。
3. 在“PPT编排要求”填写受众、详略或画风偏好；文科场景漫剧需要接入绘图或视频服务。
4. 生成结束后，结果页显示设计出的风格名和课程主题，下载 PPTX 与独立 MP4。

网页在上传前说明自动编排流程，实际风格、配色和场景在模型阅读教材后确定，并在生成结果中展示。

## 学科自适应

`course_styles.build_course_style` 向已配置模型提供课程标题、目标、知识点标题、画面要点和用户偏好。长课程明确使用分布在全课程中的概览示例，设计阶段不承担知识覆盖审核。

模型输出一份声明式设计：风格名、实际主题、设计理由、背景色、正文色、强调色、次要色、内容底色、标题尺度，以及轨道、等高线、网格、色带、点阵或曲线等矢量装饰语汇。程序将其应用到用户选择的基础版式，而不是从教材名称中寻找预设的学科配色。

程序保证正文在两种内容底色上的对比度至少为 4.5，次要文字和强调图形至少为 3。淡色前景会在保留色相的前提下调整明度，模型原值与渲染值分别保存。模型不能提交 SVG、代码、图片路径或远程图片地址。

PPT 与视频通过 `effective_template` 读取同一份设计，媒体缓存包含设计与课程内容指纹。旧任务仍使用原固定模板，改变偏好或讲稿会使相应新设计缓存失效。

## 场景漫剧流程

新任务采用动漫电影式场景分镜，而非固定师生对话。先由本机或授权学院服务器模型设定世界观、美术方向、角色外貌服装及地点；随后读取全部原文，为每1至2句安排一个镜头。镜头包含人物、地点、景别、镜头运动意图、具体行动、构图和承接说明。人物数量由内容决定，诗词可使用无人风景或物件特写；辅助角色标为情境演绎，不伪装成教材中的历史人物或事件。

模型只提交原句编号，程序回填完整原句和字符区间，检验句子覆盖、先后顺序、人物/地点编号及旁白指纹。原文作为旁白和字幕，不改成角色对白。角色设定跨镜头复用；当前媒体协议发送文字描述，尚无参考图条件控制，不保证生成器自动保持同一张脸。

每镜必须有实际生成的插画或视频。至少配置一种媒体服务；同时配置时优先视频。生成前检查镜头总数与用户素材上限（默认12，最高200），超额不提交请求。没有配置、缺镜头、请求失败或文件校验失败时明确停止，不回退成讲师学员、黑板气泡或重复静图。失败请求和已完成素材保留，付费请求不会自动重复创建。

PPT每页以完整场景关键帧为主体，保留原文与分镜备注，不嵌入音视频。MP4依次衔接场景并使用原文音频一次；视频素材的自带声音丢弃，短素材结束后保持末帧，不循环播放。镜头时点优先使用真实分句音频时长，在同一分句内部按字符插值，不称为逐字强制对齐。仅绘图时为插画分镜序列；接视频时才有模型生成的动态画面。

旧版 `comic_story.version=1` 的师生对话任务仍按原格式重放；新任务使用 `format=scene_drama`、version=2，不能把旧结果当成新的动漫场景效果。

## 接口与记录

API继续兼容以下 `style_mode`；网页的AI新建与重试统一使用 `subject` 和 `animation_mode=auto`，不恢复旧任务的手动选择：

| 值 | 用途 |
| --- | --- |
| `subject` | 新网页默认，先识别学科再选模板；人文使用场景漫剧 |
| `template` | 固定模板，默认值，兼容原任务 |
| `adaptive` | 基于课程内容生成视觉设计 |
| `comic` | 世界观、人物与场景设定、动作分镜及实际绘制素材 |

自适应与漫剧需要真实 AI 模式。语言模型规划只使用本机或已授权学院服务器；场景素材另需用户配置绘图/视频服务。接口模拟测试只验证接入与导出，不代表已生成参考示例那样的动漫作品。

任务中的 `course-style/style-drama.json` 和 `drama-story.json` 保存设定及全部镜头；`presentation-plan.json` 保留最终计划。`drama-production.json` 保存镜头素材与生成状态；`presentation-preview/manifest.json` 记录实际页面、原句区间、素材、时序和配音使用次数。生成素材有SHA256校验，密钥不写入记录。

用已有课程片段检查新风格时，原讲稿与音频可以复用；这种验证单独记录为风格设计与媒体导出，不重计为一次完整教材理解实验。
