# 原文课程与学科编排

## 生成顺序

1. 逐页提取PDF文字，必要时本机OCR，保留页码和OCR标记。
2. 程序按原文顺序切分，不删除重复段、标题、图注或条件；保存页码、起止字符、原文和页文本SHA256。
3. 本地模型阅读均匀取样的来源片段判断学科，另一次调用从预建模板族选择呈现方式。取样不会影响字幕覆盖。
4. 模型逐段规划PPT要点、SVG、故事阶段、绘画描述或可计算演示请求。字幕与配音直接复制原文，不接受模型替换。
5. 按可读字幕长度分句配音，用每句实际WAV时长确定字幕时间，导出前核对完整原文、语音输入与字幕。
6. 导出静态PPTX与独立有声MP4。完整画面缩放至字幕栏上方，不裁掉图示；每段原文音频仅使用一次。

原文保真基于提取/OCR文本，不等于像素级识别准确率。全文下载按页加入分隔符；精确文本和字符区间以课程及字幕JSON为准。SRT/VTT只规范空白行和换行，不省略正文、公式或标点。

## 模板与提示词

| 模板族 | 模板ID | 视觉组织 |
| --- | --- | --- |
| 数理化 | `stem_board`、`stem_lab` | 数理推演、实验与过程；原创图形、变量、单位、原例和可计算场景 |
| 语言与人文 | `language_story`、`language_comic` | 原创矢量人物、按原文次序安排故事线，可追加绘制插图和生成视频 |
| 专业与工程 | `professional_system` | 实体、结构、系统依赖及操作步骤 |
| 综合 | `paper`、`academic` | 保留混合内容，逐段选择表达形式 |

学科判断基于实际内容，不用文件名关键词匹配学科。人文自动使用场景漫剧，按地点、人物行动和镜头组织画面，其他模板族使用图形表达；高级 API 可显式指定其他模式。3Blue1Brown仅作为逐步解释的教学方式参考，不复制素材。生成图片不用于证明数学关系。

## 原创绘图与视频接口

网页提供两组独立配置，均默认关闭：

- 绘图：`image_protocol=images`，根地址、模型ID和任务密钥；追加`/images/generations`，接收`data[0].b64_json`或图片URL。
- 视频：`video_protocol=seedance`，根地址（含`/api/v3`等路径）、模型/接入点ID与密钥；追加`/contents/generations/tasks`创建任务，再按任务ID查询`content.video_url`。请求关闭生成音频，成片只用教材配音。
- `art_max_assets`限制图片与视频的总生成数，默认12，上限200。小云雀等服务若无上述协议，需要兼容网关；不假定存在统一原生API。

仅发送已选场景描述，不上传整份PDF或音频；远程调用须显式同意。密钥不保存到SQLite、日志或浏览器；服务中断后须重新输入。下载限制大小、地址及重定向，先实际解码再进入课件。插画标为原创生成，不能冒充教材原图。视频结束后保持末帧，不循环重复；供应商音轨不进入成片。

创建请求结果不明或失败时保留状态，不自动重复提交付费请求。已知视频任务重试时继续查询原ID。未配置外部服务时，人物故事线使用项目自己绘制的矢量角色，不暗中检索照片。

协议参考：[Images接口](https://developers.openai.com/api/reference/resources/images)、[Seedance视频任务查询](https://docs.volcengine.com/docs/ark/get-video-generation-task-api?lang=zh)。协议兼容测试不等于调用过某家收费服务。

## API与导出

新网页AI新建与重试统一使用`narration_mode=source_verbatim`、`style_mode=subject`、`animation_mode=auto`，取消呈现方式、模板、动画和生成策略的手动选择。确定性演示使用固定模板。旧客户端不传新字段时继续提炼讲解；旧任务重试可显式切换原文课程。

| 接口 | 内容 |
| --- | --- |
| `GET /api/jobs/{id}/subtitles?format=srt\|vtt\|json` | 字幕与逐字时间线 |
| `GET /api/jobs/{id}/transcript` | 全文（含页分隔） |
| `GET /api/jobs/{id}/source-coverage` | 逐页字符覆盖记录 |

仅完成的任务提供下载。实际学科、取样、模板理由、故事线与生成媒体记录保存在课程和任务目录。理解与规划只用本机或已授权学院服务器模型，不使用DeepSeek或云语言模型；外部图像/视频须单独配置和同意。

可计算场景保留来源、几何与数值校验。构造失败时保留原文、SVG及记录，不关闭校验强行生成。变化时长适配完整原文音频，尚未逐词对齐对象动作。

场景漫剧须配置绘图或视频服务，每镜绑定实际素材。字幕与配音仍完整使用教材原文作为旁白，不能改成固定师生对话。具体分镜与素材规则见[学科风格与漫剧](学科风格与漫剧.md)。

逐段计划记录模型选择的`medium`，执行后记录`executed_medium`，结果页显示实际采用的画面。计算构造未完成时保留SVG图解和警告，不将该次输出标为连续动画成功。独立的空说明标签若重复了同一关系名称，会归入边标签并保留完整别名和原始草稿。
