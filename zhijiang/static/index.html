02生成方式

字幕与配音逐字朗读教材原文，PPT提炼要点、绘制图示。扫描教材以识别文本为准，可下载全文与逐页核对记录。

模型设置
数学模型（可选）

自动编排

模型阅读教材后，自动识别学科，选择课件风格、页面布局以及图示或动画。你可以在“PPT编排要求”中描述希望达到的效果。

文科采用场景漫剧，数理化按内容组织图形与推演；实际采用的方案会在生成结果中显示。原创绘图和视频服务可在下方接入。

个性化学习规划 可选

模型根据课程片段安排学习、复习与自测。学习计划单独输出，字幕与配音仍完整保留教材原文。

原创插画与视频接口 可选

场景漫剧需配置绘图或视频服务：先设定人物与地点，再逐镜绘制完整动漫场景。绘图接口输出插画分镜，视频接口输出动态片段；同时开启时漫剧优先使用视频。仅发送场景描述，小云雀等服务需兼容网关，视频支持Seedance任务协议。密钥仅用于本次任务。

Seedream等图片模型用于绘制人物与场景，Seedance用于生成动态视频。火山方舟接口根地址可填 https://ark.cn-beijing.volces.com/api/v3，模型ID使用你已开通的图片或视频模型；两类模型分别填写，不要互换。

即梦3.0使用API Key入口 https://openapi.cv.volces.com，模型填 jimeng_t2i_v30，密钥填 API Key Secret；不填ID、不使用签名鉴权域名。单镜提示词超过800字符会在提交前提示调整。

漫剧每镜对应一份素材。生成前会核对分镜总数，超过上限时提示调整，不会自动增加调用。
